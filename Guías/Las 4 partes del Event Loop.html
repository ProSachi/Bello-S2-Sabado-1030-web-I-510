Código

 


    
Web APIs
Herramientas del navegador, no de JS: setTimeout, DOM, fetch. JS les delega las tareas de tiempo o de red.

    
Call Stack
Lo que JS ejecuta ahora mismo. LIFO: el último en entrar es el primero en salir. Solo cabe una a la vez.

    
Event Loop
Ciclo infinito con una sola pregunta.
¿Está vacío el Call Stack?

    
Callback Queue
Aquí espera el resultado de la Web API hasta que le toque su turno.
